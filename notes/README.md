# Заметки по новостям

Здесь автоматически появляются суточные заметки: изменения правил и практики белых списков, решения операторов,
технические публикации, новые профильные репозитории.

- Собирает `.github/workflows/news.yml` (раз в сутки, плюс запуск вручную из вкладки Actions).
- С ключом `GROQ_API_KEY` (бесплатный тариф api.groq.com, модель `openai/gpt-oss-120b`) заметку пишет LLM:
  тезисы по существу и раздел «что это значит для белых списков».
- Без ключа — экстрактивный дайджест: заголовки, источники, ссылки, без выводов.
- Формат имени файла: `ГГГГ-ММ-ДД.md`.

Правила: только публичные источники, ссылка на первоисточник обязательна, персональных данных нет,
никаких оценок достоверности без проверки — сомнительное помечается как неподтверждённое.

Заметки — это контекст, а не данные. Проверенные списки живут в [`../whitelist.txt`](../whitelist.txt)
и [`../data/upstream/`](../data/upstream).
