# Russia Whitelist

Белые списки мобильного интернета России: домены (SNI), подсети и IP операторов, инструменты проверки и гайды.
Russia mobile internet whitelist: domains, CIDR ranges and IPs, checking tools and guides.

- Данные: [`whitelist.txt`](./whitelist.txt), [`data/upstream/`](./data/upstream)
- Проверка: `python3 tools/wlcheck.py --ip <адрес>`
- Выжимка для ИИ-агентов: [`llms.txt`](./llms.txt)
- Форум (Q&A, конфиги, опыт по регионам): [Discussions](https://github.com/kort0881/russia-whitelist/discussions)
