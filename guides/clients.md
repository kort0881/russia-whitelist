# Клиенты: что поставить и как импортировать ссылку

## Windows

| Клиент | Плюсы | Минусы |
|---|---|---|
| v2rayN | поддержка всех современных протоколов, импорт ссылок, подписки | интерфейс перегружен |
| Throne (бывш. NekoRay) | аккуратный интерфейс, sing-box/xray внутри | требуется актуальная версия |
| Hiddify | простой, для новичка | меньше тонких настроек |

Импорт: скопировать `vless://...` → в клиенте «Серверы» → «Импорт из буфера обмена» → выбрать сервер → проверить,
что в параметрах совпадают `security=reality`, `flow=xtls-rprx-vision`, `pbk`, `sid`, `sni`.

## Android

- v2rayNG — универсальный, импорт ссылок и подписок;
- Husi / HAPP — удобнее для подписок (`?f=happ` для совместимого формата);
- Streisand (iOS) — для iPhone.

## iOS

Streisand, FoXray, HAPP. Импорт через буфер обмена или добавление подписки по URL.

## Что проверить, если «подключено, но не работает»

1. `flow` в клиенте и на сервере совпадает (`xtls-rprx-vision`), либо отсутствует с обеих сторон.
2. `pbk` — публичный ключ, а не приватный.
3. `sid` — shortId из конфига сервера, без лишних символов.
4. `sni` совпадает с `serverNames` на сервере.
5. Время на устройстве верное (расхождение больше пары минут ломает TLS).
6. Клиент обновлён: старые версии не умеют актуальные параметры Reality.

## Ссылки и подписки

Универсальный вид ссылки:

```
vless://UUID@АДРЕС:443?encryption=none&security=reality&flow=xtls-rprx-vision&fp=chrome&pbk=ПУБЛИЧНЫЙ_КЛЮЧ&sni=ДОМЕН&sid=SHORT_ID&type=tcp#Имя
```

Подписка — это URL, по которому клиент сам забирает список серверов. Подписки удобнее, когда серверов несколько
или когда адрес меняется: пользователю не нужно пересылать новую ссылку.

## Безопасность

- не публикуйте свои ссылки и конфиги: это фактически ключ доступа;
- не пересылайте ссылки в открытые чаты и в обсуждения репозитория;
- при утечке меняйте UUID клиента на сервере — это дешевле, чем менять ключи Reality у всех.
